# Fibonacci · Interface Node

Interface web em Node.js/Express para o gerador de Fibonacci do projeto.

## O que a interface faz

- Calcula o termo **Fₙ** (F₀ = 0, F₁ = 1)
- Gera uma sequência com N termos
- Verifica se um número pertence à sequência
- Calculadora aritmética (soma, subtração, multiplicação, divisão e %)
- Tabela periódica interativa (118 elementos, busca e ficha)
- Usa `BigInt` para índices altos (até 2000)
